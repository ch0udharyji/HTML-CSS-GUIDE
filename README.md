## 📖 Overview

This repository provides a comprehensive, aesthetic, and easy-to-use cheat sheet for HTML and CSS. It's designed to help beginners quickly grasp web development fundamentals and serve as a handy reference for experienced developers.

## 🗂️ Repository Structure

- **[`index.html`](./index.html)**: The sleek, minimal landing page serving as an entry point to the guides.
- **[`terms.html`](./terms.html)**: **Basic Terms** - A glossary of essential web development terminologies to get you started.
- **[`html.html`](./html.html)**: **HTML Cheat Sheet** - A quick reference for essential HTML tags, document structure, semantic elements, forms, and more.
- **[`css.html`](./css.html)**: **CSS Cheat Sheet** - A comprehensive guide covering CSS properties, selectors, layouts (Flexbox/Grid), typography, and styling basics.
- **[`style.css`](./style.css)**: The core stylesheet giving the project its modern, dark-themed, and responsive design.
- **[`script.js`](./script.js)**: Contains interactivity logic to enhance the user experience across the cheat sheet pages.


## Features

- **Responsive Layout**: Fully functional and beautiful on both desktop and mobile devices.
- **Quick Navigation**: Easily jump between foundational terms, HTML structures, and CSS styling concepts.
