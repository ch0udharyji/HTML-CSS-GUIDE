Selectors #

Targeting Elements

CSS selectors define the elements to which a set of CSS rules apply.

ID Selector (#demo-id) 
/* Element Selector */
p { color: #333; }

/* Class Selector */
.highlight { background-color: yellow; }

/* ID Selector */
#main-header { font-size: 2rem; }

/* Descendant Selector (space) */
article p { line-height: 1.6; }

/* Direct Child Selector (>) */
ul > li { list-style: none; }

/* Pseudo-classes */
a:hover { text-decoration: underline; }
li:nth-child(even) { background: #eee; }

Box Model #

Margin, Border, Padding, Content

The foundation of layout on the web. Every element is a rectangular box.

Content

Red: Margin | Yellow: Border | Green: Padding | Blue: Content

.box {
  /* Crucial: Includes padding and border in element's total width/height */
  box-sizing: border-box; 
  
  width: 100%;
  max-width: 400px;
  height: 200px;
  
  margin: 20px auto; /* 20px top/bottom, auto left/right (centers it) */
  padding: 15px;     /* Space inside the border */
  border: 2px solid black;
}

Colors & Backgrounds #

Colors and Gradients

Applying colors, opacity, and gradient backgrounds.

Gradient Background 
.element {
  /* Text color formats */
  color: #ff0000;              /* Hex */
  color: rgb(255, 0, 0);       /* RGB */
  color: rgba(255, 0, 0, 0.5); /* RGB + Alpha (Opacity) */
  color: hsl(0, 100%, 50%);    /* Hue, Saturation, Lightness */
  
  /* Backgrounds */
  background-color: #f8f9fa;
  background-image: linear-gradient(to right, #6366f1, #ec4899);
  background-size: cover;
  background-position: center;
  
  opacity: 0.9; /* Makes entire element transparent */
}

Display & Position #

Document Flow

Control how elements take up space and align themselves.

Absolute (Top Right)
Relative Block
.display {
  display: block;       /* Takes full width, starts new line */
  display: inline;      /* Wraps content, ignores width/height */
  display: inline-block;/* Wraps content, respects width/height */
  display: none;        /* Removes from document completely */
}

.positioning {
  position: static;     /* Default document flow */
  position: relative;   /* Shifted relative to normal position */
  position: absolute;   /* Positioned relative to nearest positioned ancestor */
  position: fixed;      /* Fixed to viewport (window) */
  position: sticky;     /* Toggles relative/fixed based on scroll */
  
  top: 0; left: 0;      /* Coordinates */
  z-index: 10;          /* Stack order (higher is closer to user) */
}

Flexbox #

1-Dimensional Layout

Perfect for aligning items in rows or columns and distributing space.

Item 1
Item 2 (Grow 2)
Item 3
.flex-container {
  display: flex;
  flex-direction: row;      /* row | column */
  justify-content: center;  /* center | space-between | flex-start */
  align-items: center;      /* stretch | center | flex-start */
  flex-wrap: wrap;          /* allows items to wrap to next line */
  gap: 15px;                /* spacing between items */
}

.flex-item {
  flex-grow: 1;    /* Distribute remaining space */
  flex-shrink: 0;  /* Prevent shrinking */
  flex-basis: auto;/* Initial size */
  /* Shorthand: flex: 1 0 auto; */
}

Grid #

2-Dimensional Layout

Perfect for complex, rigid page structures mapping columns and rows.

Header (Span 3)
Sidebar (Span 2 rows)
Content 1
Content 2
Footer (Span 2)
.grid-container {
  display: grid;
  grid-template-columns: repeat(3, 1fr); /* 3 equal fraction columns */
  grid-template-rows: auto 1fr auto;
  gap: 20px;
}

.grid-item {
  grid-column: 1 / 4; /* Start line 1, end line 4 (spans 3 columns) */
  /* OR */
  grid-column: span 3;
  grid-row: span 2;
}

Typography #

Fonts and Text Styling

Controlling the appearance of text.

p {
  font-family: 'Helvetica Neue', Arial, sans-serif;
  font-size: 1.2rem;       /* 1.2x root font size */
  font-weight: 600;        /* 100-900 or normal/bold */
  line-height: 1.5;        /* Spacing between lines */
  letter-spacing: 0.05em;  /* Spacing between letters */
  
  text-align: center;      /* left | right | center | justify */
  text-transform: uppercase;/* uppercase | lowercase | capitalize */
  text-decoration: none;   /* none | underline | line-through */
}

Borders & Shadows #

Depth and Outlines

Card Element 
.card {
  border: 2px solid #3b82f6;
  border-radius: 12px;
  
  /* x-offset y-offset blur spread color */
  box-shadow: 0 4px 6px -1px rgba(0, 0, 0, 0.1);

  outline: 2px dashed red;
}

Transitions & Animations #

State Changes and Keyframes

/* Transitions (A to B state change) */
.btn {
  background: blue;
  /* property duration timing-function delay */
  transition: background 0.3s ease, transform 0.2s;
}
.btn:hover {
  background: darkblue;
  transform: translateY(-5px);
}

/* Animations (Complex multi-step) */
@keyframes spin {
  0% { transform: rotate(0deg); }
  100% { transform: rotate(360deg); }
}
.loader {
  animation: spin 1s linear infinite;
}

Variables & Functions #

Custom Properties & Math

:root {
  --primary: #3b82f6;
  --spacing: 1rem;
}

.box {
  background-color: var(--primary);
  padding: calc(var(--spacing) * 2); /* Math in CSS */
  
  /* Clamp: min, preferred, max */
  font-size: clamp(1rem, 2.5vw, 2rem); 
}

Responsive Design #

Media Queries

Apply styles only when device criteria are met (like screen width).

/* Mobile-first approach (default styles for small screens) */
.container {
  flex-direction: column;
}

/* Apply changes when screen is wider than 768px (Tablets/Desktops) */
@media (min-width: 768px) {
  .container {
    flex-direction: row;
  }
}

/* Dark mode detection */
@media (prefers-color-scheme: dark) {
  body { background: #111; color: #fff; }
}
