1. Document Structure & Metadata #

The Basic Boilerplate

Every HTML5 document starts with these essential tags to define its structure and metadata.

<!DOCTYPE html> <!-- Declares HTML5 version -->
<html lang="en"> <!-- Root element with language attribute -->
  <head>
    <!-- Metadata: Data about data -->
    <meta charset="utf-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta name="description" content="Site description for SEO">
    
    <!-- Title & Base -->
    <title>Page Title</title>
    <base href="https://example.com/"> <!-- Base URL for relative links -->
    
    <!-- Styles & Scripts -->
    <link rel="stylesheet" href="style.css">
    <style> /* Inline CSS goes here */ </style>
    <script src="script.js" defer></script>
    <noscript>Please enable JavaScript to view this site.</noscript>
  </head>
  <body>
    <!-- Visible content goes here -->
  </body>
</html>

6. Semantic Layout (HTML5) #

Architecture Tags

Semantic tags describe their meaning to both the browser and the developer.

<header> <!-- Page/section header -->
  <hgroup> <!-- Group of headings -->
    <h1>Main Title</h1>
    <p>Subtitle</p>
  </hgroup>
</header>

<main> <!-- Dominant content area -->
  <article> <!-- Independent, self-contained content -->
    <section> <!-- Thematic grouping -->
      <figure> <!-- Grouping media -->
        <img src="...">
        <figcaption>Image caption</figcaption>
      </figure>
    </section>
  </article>
  <aside> <!-- Indirectly related content / Sidebar --> </aside>
</main>

<footer> <!-- Page/section footer --> </footer>

11. Accessibility (A11y) Best Practices #

ARIA Roles, States & Focus

Mandatory attributes for Screen Readers and assistive technologies.

<!-- ARIA Roles -->
<div role="alert">Error occurred!</div>
<div role="button" tabindex="0">Div acting as a button</div>
<nav role="navigation"></nav>

<!-- ARIA States -->
<button aria-expanded="false">Menu</button>
<ul aria-hidden="true"></ul>
<input aria-invalid="true">
<button aria-pressed="false">Toggle</button>

<!-- Screen Reader Labels -->
<button aria-label="Close dialog">X</button>
<input aria-labelledby="label-id" aria-describedby="desc-id">

<!-- Focus Management -->
<div tabindex="0">Focusable div</div>
<a href="#" tabindex="-1">Unfocusable link</a>
